# Budgeted fault-evidence retention

The project's research focus is now **which native observations to preserve when
storage and downlink are limited**, so an independent receiver can still detect
or investigate unfamiliar faults. Existing statistical/PCA detectors are capture
or receiver components, not the research endpoint by themselves.

## Current implementation

`python/retention/` is an initial Python research prototype:

| Module | Responsibility |
| --- | --- |
| `codec.py` | Native timestamp samples and explicit packet/record encoding and validation |
| `recorder.py` | Uniform, extrema-summary, threshold-only, and adaptive capture policies |
| `evaluation.py` | Decoded-packet raw coverage, onset/context, and synthetic receiver checks |
| `../run_retention_demo.py` | Seeded replay, serialized packet files, JSON report, generated LaTeX table |

All policies receive the same observations and budget cap. The recorder has no
label input. Adaptive capture uses a bounded pre-trigger ring, a post-trigger sample
count, and a separate quota for time-stratified background samples chosen without
anomaly scores. There is no budget borrowing; background quota is not reclaimed
if unused. Native observations, rather than forward-filled frames, are the input.

Run from the repository root:

```bash
python python/run_retention_demo.py --latex paper/generated/smoke_results.tex
PYTHONPATH=python python -m unittest discover -s python/tests -p 'test_retention.py' -v
```

The default output is `data/results/retention-smoke/`. Packet files use `.taer`;
`report.json` includes configuration, script hashes, actual serialized bytes,
allocated bytes, and event-level details. A small copy is tracked in
`docs/results/retention-smoke.json`. The generated table belongs to the
[LaTeX manuscript](../paper/README.md).

## Experimental wire contract

Every active reporting epoch emits one packet. Empty epochs emit nothing and do
not bank capacity. Every timestamp is an integer Unix-style microsecond offset;
the synthetic scenario uses a zero origin. All multi-byte fields are little-endian.

| Item | Encoding | Bytes |
| --- | --- | ---: |
| Packet header | `4s HH q Q I I`: magic `TAER`, version 1, header size, epoch start, duration, byte cap, record count | 32 |
| Record prefix | `B B H`: type, reason flags, payload length | 4 |
| Raw payload | `q 6f`: native timestamp and six binary32 values | 32 |
| Summary payload | `q 6f 6f I`: bucket start, channel minima/maxima, raw count | 60 |

Raw and summary records therefore cost **36 and 64 bytes**. Packet encoding enforces
`32 + 36 * raw_count + 64 * summary_count <= budget_bytes`. Raw reason bits are
periodic (1), trigger (2), pre-trigger (4), post-trigger (8), and background (16).
A deduplicated sample records its first selection reason. The decoder rejects
invalid headers, unknown records/flags, invalid bounds, nonfinite values, duplicate
raw timestamps, out-of-epoch records, truncation, and trailing bytes.

Summary slots are derived from the packet cap and epoch duration. An empty slot
has no record. A summary cannot reconstruct precise sample order or source times.
Its receiver event overlap is coarse evidence and is reported separately from raw
coverage. Production link framing, checksums, cryptography, acknowledgements,
retries, and model transfer remain outside this experimental byte contract.

## Memory and causality boundaries

One recorder retains one epoch's packet records plus a configured sample ring.
The count is bounded by configuration. This is not a measured Python RSS bound
or an embedded allocation guarantee. The smoke driver deliberately collects a
small full source and completed packets for evaluation; a streaming source/sink
must replace that in native mission integration.

A trigger may preserve previous buffered observations because they were already
available. Future observations cannot change finalized packets. Context and quotas
reset at an epoch boundary. Calling `finish()` cannot reopen that same epoch to
spend the quota again. Samples are chronological, finite, and canonicalized to
binary32 before decisions. No synthetic fills are generated by the recorder.

## Research milestones

| Milestone | Deliverable | Status |
| --- | --- | --- |
| R0 | Research question, packet accounting, four causal reference policies, tests, manuscript scaffold | Implemented |
| R1 | Reproducible synthetic serialization/context checks and generated paper table | Implemented |
| R2 | Native Mission1 validation pilot, stronger sampling baselines, independent receiver, budget sweep | Next |
| R3 | Contact/queue/loss model, memory instrumentation, C++ recorder parity | Planned |
| R4 | Frozen independent-mission study, uncertainty and operational engineering review | Planned |

For R2, use the original synchronized channel series from `load_aligned_channels`,
not reconstructed 30-second frames. Fit transforms and capture/receiver models on
training only. Evaluate first on a declared validation window and preserve precise
channel-specific labels. The existing Mission1 test split has already been
examined; a new independent estimate requires another untouched mission or dataset.

Required ablations include no pre-context, no background reservation, no post-context,
ring sizes, epoch-boundary behavior, trigger/receiver swaps, threshold sensitivity,
and budget sweeps. Compare at a common cap while plotting actual expenditure.
Add a full-archive reference and stronger adaptive/random sampling controls before
claiming superiority. Recording faults in a toy scenario is not evidence of
improved diagnosis; an engineering partner must define that endpoint.
